# RFC: Gooo Workgraph External Consumer Contract v1

Status: Proposed

## Decision

Gooo Workgraph is a separate public project. It must not import internal Go
packages, branches, or `go.mod` replacements from `meta-ontology-go`. It may
consume only a released `gooo` executable and explicitly versioned JSON or
NDJSON wire schemas.

This boundary makes external utility falsifiable. A missing core release is
`UNKNOWN`; a development checkout is not silently accepted as a release.

## Fixed seven-gate observer denominator

| Gate | Stage / step | Proof choice |
|---|---|---|
| `SOURCE_AUTHORITY` | `SOURCE / DECLARE_AUTHORITY` | `FOUNDATION` |
| `SYNTAX_ACCEPTED` | `COMPILER / CHECK_SOURCE` | `FOUNDATION` |
| `META_BOUND` | `META / BIND_ACTIVITIES` | `COHERENCE` |
| `DETERMINISTIC_REPLAY` | `GENERATOR / REPLAY_GENERATION` | `REGRESSION` |
| `ARTIFACT_GENERATED` | `GENERATOR / EMIT_ARTIFACT` | `COHERENCE` |
| `RESOURCE_OBSERVED` | `RUNTIME / SAMPLE_RESOURCES` | `REGRESSION` |
| `USER_ROUNDTRIP` | `USER / CLOSE_CLAIM` | `COHERENCE` |

Gate order and denominator `7` are part of `gooo/workgraph-project/v1`.
Adding or removing a gate requires `v2`.

## Claim and incomplete knowledge

Allowed cell states are `CLOSED`, `UNKNOWN`, and `REFUTED`. Every `UNKNOWN`
must retain `stage`, `step`, `reason`, and `next_operation`. A later report
must retain the predecessor digest and the previous claim coordinates.
Natural-language confidence cannot close a cell.

- Missing evidence is `UNKNOWN`.
- Present evidence that contradicts a predicate is `REFUTED`.
- Any refuted predecessor gate refutes `USER_ROUNDTRIP`.
- Only seven closed gates discharge the claim.

The proof choices are not scores. `FOUNDATION` identifies authority,
`COHERENCE` checks structural relationships, and `REGRESSION` requires a
second observation. An evaluator cannot choose an easier branch.

## Read-only effect boundary

The first observer may read source, contracts, and existing receipts. It may
write artifacts only outside the input repository. `repository_writes` counts
persisted input-repository path changes. If a pre/post snapshot is absent, the
value is unknown, not zero.

## Replay and refutation

Replay compares raw generated bytes and stable manifest fields. Absolute
paths, timestamps, temporary directories, and resource measurements do not
participate in byte equality. A one-byte replay mutation must produce:

```text
decision = FAIL_CLOSED
resolution = EXACT
closed = 5/7
unknown = 0/7
refuted = 2/7
next_operation = RESOLVE_EVIDENCE_CONTRADICTION
```

The two refuted gates are `DETERMINISTIC_REPLAY` and `USER_ROUNDTRIP`.

## Human indicators

The observer reports exact numerators and denominators for closed gates
(`7`), replay pairs (`1`), resource samples (`1`), discharged claims (`1`),
preserved unknown transitions, and read-only runs. It always reports unknown,
refuted, active, contested, discharged, and repository-write counts.

Resource scope includes Workgraph capture/evaluation and child `gooo`
processes. It excludes checkout, dependency download, CI queue time, artifact
upload, network waiting, and unrelated runner load. v1 asserts no latency SLA.

## Release slices

1. `v0.1.0` observes the released core, source/head binding, and a pre/post
   repository snapshot. Expected observer state: `4/7 CLOSED`, `3 UNKNOWN`,
   `0 REFUTED`, `repository_writes=0`.
2. `v0.2.0` executes two external-temp generations, compares raw bytes,
   records one resource sample, consumes a predecessor, and emits chained
   NDJSON. Expected state: `7/7 CLOSED` and one discharged claim.
3. `v1.0.0` adds byte-mutation, predecessor-identity, and unsupported-schema
   counterexamples plus a released-core compatibility matrix.

## Compatibility

Core and Workgraph releases are independent. Workgraph locks the exact core
version and binary digest. Additive JSON fields are allowed within a schema
major, while new decision enum values lower resolution to `UNKNOWN`. Gate or
state semantic changes require a new schema major. A Workgraph compatibility
failure never blocks an unrelated core merge.

The design borrows only boundary principles from Cargo machine output, Bazel
Build Event Protocol, Nix input locks, in-toto attestations, and SLSA external
parameters. It does not claim compatibility or compliance with those systems.
